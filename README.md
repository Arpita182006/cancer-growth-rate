Cancer Growth Rate Prediction Using Machine Learning

Cancer Growth Rate Prediction is a machine learning-based project designed to predict the growth rate of a tumor using patient and tumor-related information.

The project uses a Random Forest Regression model trained on clinical and patient-related features such as age, gender, previous tumor size, time since diagnosis, cancer stage, genetic risk, lifestyle factors, BMI, and treatment information including chemotherapy, radiotherapy, and surgery.

The trained machine learning model is saved as a Pickle (.pkl) file, which can later be integrated into a web application. The planned website will provide an easy-to-use interface where users can enter the required parameters and receive the model's predicted tumor growth rate.

Main Features
Patient and tumor information input
Machine learning-based growth-rate prediction
Random Forest Regression model
Prediction through a web interface
Simple and user-friendly result display
Technology Used
Python
Jupyter Notebook
Pandas & NumPy
Scikit-learn
Random Forest Regression
Pickle
Flask / HTML / CSS / JavaScript for the planned web application
Purpose

The project demonstrates how machine learning can be applied to healthcare-related data to generate predictive insights from multiple patient and tumor characteristics. The prediction is intended for educational and research purposes and should not be used as a substitute for professional medical diagnosis or treatment.
